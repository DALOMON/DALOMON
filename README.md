## 🚀 Proyectos Destacados

### 🧠 [Modelado Predictivo en Alzheimer y Esclerosis Múltiple (EM)](link-al-repo)
*Investigación y análisis de datos clínicos longitudinales en enfermedades neurodegenerativas.*
Desarrollo de una red neuronal recurrente (RNN) monocapa en PyTorch para predecir la evolución y modelar patrones en pacientes.
*   **Validación Clínica:** Mitigación estricta de *data leakage* mediante estrategias de validación cruzada para datos médicos (`GroupKFold`).
*   **Interpretabilidad (XAI):** Ingeniería de mecánicas de atribución de características utilizando **Integrated Gradients** para trazar el impacto de los biomarcadores y variables clínicas sobre las predicciones (MAE), garantizando que las decisiones del modelo sean interpretables por profesionales médicos.

### ⚙️ [Motor de Prompt-Engineering y Enrutamiento](link-al-repo)
*Diseñado e implementado para CiBUC (Innovation Wars S.L.)*
Infraestructura de clasificación y enrutamiento automatizado multietapa.
*   **Arquitectura:** Modelado de flujos complejos estructurados en JSON.
*   **Evaluación:** Integración de motores de clasificación mediante rúbricas de evaluación de múltiples capas y filtros de *hard stops*.

### 🧩 [Planificadores Lógicos (PDDL)](link-al-repo)
